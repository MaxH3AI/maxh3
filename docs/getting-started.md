# Plan your first shot

## Choose the source that already contains your decision

- **Text:** useful when composition and subject appearance are still open.
- **Image:** useful when a starting composition should guide the scene. Inspect the frame for cropped hands, unclear object edges, or conflicting lighting before animating it.
- **Reference video:** useful when existing movement is the starting point. Check that the selected model accepts your reference type and format.

Open the [Max H3 workspace](https://www.maxh3.com/) and inspect the modes offered by the selected model. Input options are not interchangeable across every model.

## Make a short test brief

Write one sentence for each of the following: subject, visible action, camera, lighting, sound, and ending. If two instructions fight each other, choose which matters more before generating. For example, a locked camera and an orbit describe different camera behavior.

Choose a short available duration and an appropriate preview resolution. Read the credit estimate before submitting. Use the live workspace for current limits and costs.

## Review one variable at a time

Watch once for the overall action, then again for continuity. Compare the subject at the first and last frame. Check whether the motion completes and whether the camera reaches the intended framing.

Record a small experiment log:

| Field | What to record |
| --- | --- |
| Input | Text or a reference you may use |
| Settings | Model, mode, duration, resolution, aspect ratio |
| Brief | Exact prompt used |
| Observation | One specific success or failure |
| Next change | One instruction or setting to adjust |

Try the [product video brief](../examples/product-video.md) or [character movement brief](../examples/character-motion.md). Do not change the prompt, model, and reference simultaneously if you want to understand which change helped.
