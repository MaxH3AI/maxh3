# Choose a LoRA for a specific shot

Begin with the effect you want to change. Browse the [MiniMax H3 LoRA collection](https://www.maxh3.com/minimax-h3-loras), read the selected workflow's input requirements, and inspect its examples before submitting a generation.

## Separate motion from appearance

- A **motion goal** describes what the camera or subject does: tracking, pushing closer, or changing perspective.
- An **appearance goal** describes how the scene looks: analog texture, illustration, clay, or pixel-based styling.

For an initial comparison, choose one primary goal. Stacking several unrelated style instructions makes it harder to tell whether the selected workflow helped.

## Compare with a useful baseline

1. Write a short, literal description of the subject and one action.
2. Save the exact prompt and input reference.
3. Check the selected LoRA's supported model and input mode. Do not assume every LoRA works with every H3 variant.
4. If a comparable baseline workflow is available, use the same brief and equivalent settings.
5. Record what changed in motion, identity, materials, and composition.

## Decide whether to keep it

A stronger visual effect is not automatically a better result. Ask whether the subject remains readable, whether the action is completed, and whether the result fits the intended edit. If styling obscures the subject, simplify the background or reduce competing descriptive instructions before trying again.

Document unsuccessful attempts as well as successful ones. A reproducible limitation is useful feedback; an unsupported claim that a LoRA always fixes a problem is not.
