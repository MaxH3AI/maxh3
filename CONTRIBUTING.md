# Contributing

Contributions should improve public documentation, explain a reproducible workflow, or clarify a product issue.

- Keep each pull request focused on one correction or example.
- For experiments, include the prompt, model, mode, settings, and what you observed.
- Clearly distinguish a suggested prompt from a generation-tested example.
- Only include text and media you have permission to share publicly.
- Add external links when they directly help explain the contribution.
- Do not submit production credentials, account data, or private application source.

For a new guide, explain the reader's problem, the steps, the limitations, and how to evaluate the result. For account-specific questions, use [SUPPORT.md](SUPPORT.md).
