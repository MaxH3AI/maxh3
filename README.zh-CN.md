# Max H3：使用指南与视频工作流

[English](README.md) · 简体中文

这里是 [Max H3](https://www.maxh3.com/?utm_source=github&utm_medium=referral&utm_campaign=product_readme_zh) 的公开使用文档、原创示例提示词和产品反馈仓库。

Max H3 是独立的 AI 创作服务。本仓库帮助你明确主体、动作、镜头和结尾画面，并通过每次只调整一个变量来比较生成结果。

## 使用方式

先确定一个短镜头要完成的动作，再选择输入方式。提交前，在工作区检查模型支持的输入、时长、分辨率和积分估算。生成后，记录最明显的问题，下次只调整一个变量。

仓库中的示例是未经生成验证的原创起始方案，不是模型评测，也不保证输出效果。具体限制与费用以在线工作区为准。
