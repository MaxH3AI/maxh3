# Support

## Public product feedback

Open an issue for a problem that can be explained without private information. Include the page URL, selected model, browser, reproduction steps, expected behavior, and actual behavior.

## Account, billing, and private generation details

Contact [support@maxh3.com](mailto:support@maxh3.com) or use the [contact page](https://www.maxh3.com/contact). Do not post account identifiers, private media, payment information, tokens, or unredacted logs in public issues.

## Security concerns

Send a minimal description privately to the same support address. Do not publish exploit details or other users' information in an issue. This repository does not promise a response time or a bounty.
