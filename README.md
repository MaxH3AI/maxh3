## A useful shot brief

Write down these six decisions before generating:

1. **Subject:** what is visible at the beginning?
2. **Action:** what single event happens during the shot?
3. **Camera:** is it locked, moving closer, tracking, or orbiting?
4. **Appearance:** which materials, lighting, and background details matter?
5. **Sound:** what should be heard, if the selected workflow supports audio?
6. **End frame:** what should the audience see when the shot finishes?

Review the selected model's available inputs, duration, resolution, and credit estimate in the live workspace. They vary by workflow and may change; this repository does not provide a fixed price list.
